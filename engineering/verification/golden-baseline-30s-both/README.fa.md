# مرجع طلایی ثابت TradingBot

این پوشه در شاخهٔ `main` برای حفظ **تاریخچهٔ دقیق آزمون‌های صفر اختلاف** ایجاد شده است. **هیچ‌یک از فایل‌های اجرایی Engine تغییر نکرده‌اند.**

- مرجع تغییرناپذیر: `01d54ecf0149ebd15de92798be18810b6e2eb791`
- هفت RAW پنج‌ثانیه‌ای، مجموع **۷۹۱٬۱۷۴ کندل**، محاسبه با تایم‌فریم **۳۰ ثانیه** و جهت **both**.
- SHA256 سورس‌های اصلی: `source_blobs.json`؛ هش RAWها و خروجی‌های قطعی: `inputs.json`.
- نتایج زمان/CPU/RAM به تفکیک ورودی و نسخه: `golden_results.csv` و `version_performance.csv`.
- گزارش تست‌ها، بهینه‌سازی‌های تأییدشده و ردشده: `version_history.json`.
- اعتبارسنجی دقیق هر نسخه: `verify_golden.py` همراه با ZIP مرجع در Library حساب.

**مهم:** فایل ZIP شامل تمام خروجی‌های کامل در Library ذخیره است و **در GitHub کپی نشده**؛ این پوشه هش‌های قطعی، مسیر آرشیو، اسکریپت قابل اجرا و تمامی نتایج عددی آزمون‌های ثبت‌شده را نگهداری می‌کند. برای بازتولید، باید فایل ZIP و هفت RAW اصلی را در اختیار داشت.

**خط قرمز:** هر اختلاف در خروجی پایدار، قیمت/اعشار، ترتیب، Parent/Child، Reaction، Blue Line، A/S/E، StopAll، PH/PL، OrderAudit، Lifecycle یا Live در دامنهٔ آزمون ⇒ **FAIL و عدم انتشار**. زمان اجرا تنها استثنای عددی مجاز است و شکل آن هم بررسی می‌شود.

حذف RAW پنج‌دقیقه‌ای از مجموعهٔ فعال مطابق دستور اخیر انجام شده است. V8.2 به دلیل نداشتن افزایش سرعت پایدار، جایگزین V8.1 اعلام نشده است.
