# Zero-Difference acceptance contract (immutable oracle)

1. **Oracle**: Original GitHub commit `01d54ecf0149ebd15de92798be18810b6e2eb791`; its 15 production files verified by Git blob SHA. No optimized version may replace the oracle.
2. **Inputs**: The exact 7 `inputs.json` SHA256-pinned 5-second RAW files, full length, unmodified. Run **both directions in one native invocation** with `timeframe=30`, `raw-timeframe=5`, full bridge outputs and enabled indicator modules.
3. **Stable output**: Compare serialized bytes, including order, stringified decimal price/scale, source/provenance, reset, reaction, Blue Line, A/S/E, StopAll, PH/PL, OrderAudit, lifecycle, trend, bridge, bullish/bearish. No float tolerance, reordering, rounding, or missing fields allowed.
4. **Timing-only exception**: Exclude only *numeric measurements* in the final `timings` field from stable bytes; verify its keys and number types separately. Preserve full telemetry in the saved original/native output.
5. **Deep coverage**: Add and compare traces for meaningful internal E/reconciliation states, ownership, candidate rejection, tie-breaking, accepted ledgers, and event chronology; verify Live seed/update and error/rollback. Current snapshot tests are *selected* and cannot prove all unobserved states.
6. **Per-change gates**: For every isolated optimization, require focused unit tests, full 7 RAW pass, deterministic synthetic edge/scale data with manifest, API/CLI audit, repeated order-alternated benchmarks, CPU/RAM recording, and a final full cumulative pass. Any functional difference is an immediate rejection.
7. **Performance release rule**: Do not promote a candidate as faster solely because it passes parity. Require materially better repeated paired wall-time evidence at large scale, disclose regressions and additional memory. A candidate may remain EXPERIMENTAL with parity PASS and performance FAIL.
8. **Provenance**: Store input hashes, source full commit and Git blob IDs, Python/host versions, commands, test logs, diff, output stable SHA, run timestamp, precision and configuration. The initial environment was Python 3.13.5 on Linux with 5 reported CPU cores; observed RSS/CPU were sampled every ~25 ms.
9. **Storage**: Store full output ZIPs in Library as named under `ARTIFACTS.md` and verify SHA256 before use. Keep this directory append-only for history; never silently rewrite the original golden baseline. The existence of GitHub hashes alone does not make the missing ZIP contents available from GitHub.
10. **Honesty**: Seven completed RAWs and selected Live tests support tested-scope exactness, not a universal formal proof for all inputs/states. Never claim universal no-difference certainty.
