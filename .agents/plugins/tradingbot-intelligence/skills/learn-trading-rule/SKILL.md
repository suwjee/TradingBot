# Learn trading rule

Capture the lesson before writing code. Clarify any ambiguity that changes
eligibility, source selection, time windows, strict comparison, reset, or event
order. Formalize preconditions, candle colors, endpoint inclusion,
confirmation/invalidation, Bullish/Bearish mirror, and positive/rejected cases.

Do not promote a proposal or change production behavior without explicit user
approval. After approval, update code, focused tests, algorithm documentation,
and AI documentation as one coherent change.
