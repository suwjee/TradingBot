## Evaluation order conventions for subsequent extraction

Use source AST location, comparison operator sequence, control-site outcome labels and compiled/statement CFG together. None alone establishes exact execution. Preserve these native language behaviors when translating to language-neutral rules:

- Boolean AND evaluates operands left to right until the first falsy value; OR stops at first truthy. Preserve returned operand value when used as a callable/default rather than converting to Boolean. For example, PL_PH_detector.py:107 chooses the supplied cross or strict_cross; lifecycle_engine.py:1396–1404 chooses callback defaults before invoking them.
- Conditional expression evaluates the condition first and only the chosen alternative. The call target is selected before arguments. For example, PL_PH_detector.py:230–232 selects the lower-index crossing method; blue_line_detector.py:176–180 selects min/max only when rows exist. Do not execute both alternatives.
- Chained comparisons evaluate adjacent operands left to right, each interior operand once, short-circuiting on failure. Do not rewrite as independent repeated evaluations; see trading_pipeline.py:1758 for segment validation and reaction_engine.py:943 for suffix bounds.
- Calls evaluate target and argument expressions before entry, preserving argument evaluation and unpacking rules. Keyword-only defaults, closures, method receiver and explicit native protocol dispatch are separate bindings. Comprehensions/generators preserve outer iterable/iteration/filter order; lazy generator body executes on consumption, not on creation.
- Assignment evaluates RHS before binding target. Augmented assignment first evaluates the target, then RHS; in-place native behavior can mutate a shared object. Attribute/subscript deletion and mutation are not interchangeable with local reassignment.
- Preserve loop order and break/continue/return effects. Do not sort before a first-match selection unless source sorts. Keep first-tie/last-tie rules independent from directional comparison.
- Preserve try/except/else/finally, context-manager enter/exit and generator suspension boundaries. A finally action can run on return or error; an exception edge in the conservative CFG is only a possibility. Source has 98 explicit raises and 17 exception handlers, not a complete list of implicitly raised exceptions.
