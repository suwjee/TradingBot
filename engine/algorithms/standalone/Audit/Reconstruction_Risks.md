# Reconstruction risks

| Risk | Required proof |
|---|---|
| RAW chronology | exact same-row race cases |
| Decimal | numeric and representation equality |
| Source ownership | identity and provenance with exact event time |
| Module-specific tie | equal price/time fixtures |
| E reconstruction | invalid cause reopens race, chain regeneration and roots |
| StopAll | exact owner repeats, donor, hard boundary |
| Primary cycles | independent interleaving and proposal invalidation |
| Reversal | fresh entire main boundary, repeated direction changes |
| T/F | repeated prefix, closed confirmation and strict repair |
| Live | fresh Batch versus each append and rollback |

These are architectural risks, not proven bugs.
