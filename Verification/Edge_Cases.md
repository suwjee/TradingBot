# Edge cases and acceptance scope

Isolated tests cover primitives, T/F and aggregation. Full-engine cases not yet independently verified: empty/one candle, absent lower data, duplicate timestamp, equal price/time, confirmation/reset same RAW, stop and formation same RAW, nested reactions, multiple Orders, invalid/disowned parent, lifecycle boundary, independent roots, repeated reversal, mutable tail, rollback/retry, flags and range. This is a test plan, not PASS evidence.
