# True/False — exact recurrence and repair contract (V3)

**Conventions:** B = bullish, R = bearish. Preserve Decimal representation, evaluation order, native failures, exact versus main-candle time, original array order and nulls. Record interfaces: [Declared schemas](../../Contracts/Declared_Record_Schemas.md). Operation IDs designate semantic procedures, not required implementation symbols. This contract does not claim runtime equivalence.


## TF-X01 — Rank, repair and buffers

Priority rank: S blue=(1,0), E blue=(2,number), S red=(3,0), E red=(4,number); unknown family raises. The repair search uses original lower index through inclusive supplied horizon, left lower_bound(start), first strict Low<level B or High>level R, returns epoch or null. Do not assign a repair if key already exists, including present null. Per [public annotation](16_True_False.md), selected rows only get verdicts. Basic and StopAll recurrences are independent.

## TF-X02 — Basic recurrence (language-neutral)

Initialize repeats map (rank -> latest row, repair_count, verdict_count, base_count), references map (rank -> ordered frontier of price/verdict pairs), started=false; obtain direction policy before event iteration. Transform each Decimal source price by exact copy_negate when extreme_attr is low; otherwise use price unchanged. Iterate the complete selected chronological event stream. At every non-S/E event (directional Primary or StopAll), clear references, set started=false, set verdict_count and base_count of every retained repeat to zero, keep latest and repair_count, then continue. S starts each interval; skip E until S. Collect strictly smaller rank keys from repeats in insertion order. Compute engulf if any lower base_count >=2 and display_restart independently if any lower verdict_count >=2, both before mutation. S or engulf yields T, without requiring a price crossing; otherwise use TF08 crossed reference, invert T->F else T, or odd-number F/even T only when no reference exists. Assign current verdict. At its rank remove trailing frontier pairs while last transformed price >= current transformed price; append (price, verdict). Frontier prices therefore strictly increase: newer equal or easier-to-cross references dominate older ones. Iterate previously collected lower repeats, pop each, repair removed latest F only if repair_count==1 at current source time. Do not remove price references on repeat eviction. Same-rank previous lookup follows eviction. Initialize repair_count and verdict_count to 1. For previous non-null with same latest verdict, accumulate repair_count; only if not display_restart accumulate verdict_count and when >=2 mark both previous.latest and current REPEATED=true; if F, remove previous repair when its value (missing default -1) >= current time and attempt repair current at current time. A changed verdict starts fresh repair/display counts. Set base_count=previous.base_count+1 whenever previous exists, regardless of verdict or display_restart, else 1; store new repeat. No global surviving-counter reset on engulf. No final sweep. Existing star flags are not cleared during recurrence. Earlier rows may be mutated by repair and star; boundary retains repair history across intervals. A callback or malformed input error propagates without rollback.
See TF04/TF08 for exact evaluation order and frontier search; price-reference history is not the same object as the active repeats map.

## TF-X03 — StopAll recurrence

Initialize previous_number, previous_series_end, largest_prior_end=0; group_start and verdict_start null; prefix empty; restart flag false. New series when first or n<=previous: previous_series_end=previous_number; largest=max(old,previous_series_end); group_start=verdict_start=n; clear prefix and restart. Else restart flag sets verdict_start=n and clears flag. Update previous_number=n. Assign T iff (n−verdict_start) even. If n<=largest_prior_end append row to prefix; if n equals immediate previous end or largest prior end, and closure callback absent or true, mark every prefix row repeated and recompute parity relative group_start; set restart. Prefix stays until series reset, allowing larger match to overwrite earlier temporary verdicts. Do not add repair to StopAll. Detailed exact procedures below.

## Detailed T/F procedures

### TF01 — repair_crossing_lookup

Inputs lower index, epoch-to-time and time-to-epoch converters, keyword-only through. Compute right = upper bound of through in lower_index.times, i.e. first position strictly after through; return closure TF02 capturing that right and supplied objects. No scan at construction. Captured index and converters are references, not copies. The upper position is fixed at construction even if the referenced index changes; native callers must supply coherent index contents.

### TF02 — repair_crossing_lookup.find

Inputs direction, integer start, string level. Compute left = lower bound of converted start in index times, search limited to [0,right). Resolve policy (invalid direction raises). Select first_less if policy extreme field is low, first_greater otherwise. Convert level directly to Decimal. Call chosen search on [left,right) with threshold. If no position return null; otherwise convert index time at result position to epoch and return. Includes start and through, strict crossing according to lower index contract; equality not enough. Do not manufacture intrabar order. Exact index search implementation and converter binding are downstream open items. The return union annotation is a type expression; index position zero is a valid hit.

### TF03 — _basic_rank

Inputs key and row. If key is sZones, return pair (sequence priority for s and row.color, 0); otherwise (sequence priority for e and row.family, row.number). Priority dependency verified from the lifecycle priority contract: lowercase native string conversions of kind/family; map s/blue=1, e/blue=2, s/red=3, e/red=4; unknown key raises KeyError. Rank comparisons are lexicographic, not price-based. No row mutation. This dependency description is not counted as lifecycle module coverage.

### TF05 — _basic_verdicts.repair

Captured direction and first_crossing; inputs row and start. If callback exists AND repair field absent (present null still counts as present), call callback(direction,start,row.price). If non-null crossing returned, write repair field. Otherwise leave untouched. No separate output; callback exceptions propagate.

### TF06 — _stopall_verdicts

Inputs ordered StopAll rows, optional confirmation_closed callback. Initialize previous_number=0, previous_series_end=0, largest_prior_end=0, group_start/verdict_start=null, empty repeated-prefix list, restart=false.
For each row with number n:
- New series if group_start null or n <= previous_number. Set previous_series_end to previous_number, update largest_prior_end by max, set both start values to n, clear prefix, restart=false. Otherwise if restart flag, set verdict_start=n and clear flag.
- Set previous_number=n. Assign T if (n-verdict_start) even, F otherwise.
- If n <= largest_prior_end, append original row to prefix. When n equals previous_series_end OR largest_prior_end, and callback absent OR callback(row) truthy, revisit every retained prefix row: repeated=true, verdict T for even (its number-group_start), F otherwise. Set restart=true. Prefix is retained until series reset; a larger matching boundary may overwrite earlier temporary verdicts.

No return value, sorting or repair computation. Confirmation callback not called unless the number boundary matches. Earlier repeated flags are not explicitly removed here (TF07 clears them before collection). Equal and decreasing numbers start new series.

### TF07 — apply_true_false

Inputs direction, group mapping, first_crossing default null, keyword-only stopall_confirmation_closed default null. Choose primaryLows for exact bullish, primaryHighs otherwise. Visit collections in priority order: selected primary, stopAlls, eZones, sZones; missing collection acts as empty tuple. For each row, remove the three annotation keys if present, even for invalid/donor rows. If calculationValid is NOT the exact Boolean false, retain the first row per sourceTime (set-if-absent); subsequent same-source rows do not replace it. Sort retained pairs by sourceTime ascending; stable sorting applies, though keys are unique. A present malformed collection is not replaced with the missing-key default.
Materialize sorted events once. Traverse to set current row verdict null. Directional primary flushes and clears StopAll buffer; number in (1,2,3) is T only for 1 and F otherwise; other numbers null. StopAll rows append to stop buffer. After traversal pass ALL selected events, including boundaries, to TF04; then TF06 on remaining stops. No separate Basic buffer. No return value, no native formation or geometry mutation. Row aliasing and native exceptions remain observable without rollback.


### TF08 — _crossed_verdict

Iterate reference ranks sorted descending; only strictly smaller rank than current qualifies. At each rank, use lower_bound(current transformed Decimal price) over strictly increasing frontier prices (key first tuple element); when position is nonzero return verdict at position-1. This is the latest strictly crossed eligible reference at the greatest eligible rank; equality is excluded. If no such rank/position return null. Reference price normalization uses copy_negate for low policy, not arithmetic negation under a context. The earlier parentSourceTime-based selection is no longer used.
