# Trading Bridge — request-to-final-output algorithm (V3)

**Conventions:** B = bullish, R = bearish. Preserve Decimal representation and arithmetic order, native exception behavior, main time versus exact lower event, order and nulls. Record definitions are in [declared interfaces](../../Contracts/Declared_Record_Schemas.md). Procedure IDs designate semantic operations, not required implementation symbols. No runtime equivalence asserted.


## TB-M01 — Entry, dependency selection and input scope

Require reaction/Blue/A/S engine paths, data, timeframe, from/to and direction; E/lifecycle optional paths, Blue/A/S/primary flags default enabled, bridge-output optional, raw timeframe default1. Positive timeframe/raw timeframe required. Load engine modules once with configured names and optional primary. Lifecycle module loads by default path even when explicit StopAll flag is absent. StopAll enabled only explicit lifecycle path AND E AND S enabled. E enabled iff E engine present and S enabled. Dynamic configured modules/callbacks must satisfy referenced contracts; the source does not establish semantics of arbitrary externally supplied replacements.

Read full RAW bytes, strip BOM, decode Decimal floats, aggregate full history, establish visible range by epoch-aligned bucket bounds. Never truncate calculation at visible end. See [RAW](21_RAW_Aggregation_Contract.md). Context scope clears timestamp and market index caches before/after calculation even on error. Timed wrappers preserve result and emit progress with finally on work failure (start outside try). At module load, resolve the engine root from the bridge file, append the pipeline child and insert its exact string at the front of the import search list only when absent. Tehran zone construction and context-local progress sink initialization occur at import. Version and MBL-extension constants are declarations, not trading decisions.

## TB-M02 — Calculation stage composition

Direction request both -> B then R. If any Blue/A/S enabled, calculate both native Reaction directions for ownership. Full reusable mode iff E engine exists and S enabled; construct both full-history geometry detectors, native results and ownership. If primary present, calculate full behavior for both even single-direction request. Other mode uses independent directional initial A-stop geometry finder, native results for required directions and optional ownership; no E full state.

For each full direction:
1. Detect Blue including invalid/internal, A from full Blue, S with opposite native geometry/reset. Keep original S candidates and initial S copy.
2. Filter initial S audit by S-eligible A source. Detect initial E from accepted S. If S eligibility changes by module ownership, derive blocked S times and repeat E with valid S. Do not use provisional invalid A creation.
3. Determine invalid A by lifecycle from all S-eligible A and provisional S candidates/E. Derive invalid S and stage-specific S invalidation; remove stage-invalid S only for this next calculation. Resolve accepted Order context (including exact E exceptions); recreate E with accepted A ledger, blocked First, invalid S, Order_B legs.
4. Reconcile S decisions against shared accepted strict Order stops. If S changes, update candidate identities, rebuild E once. Find consumed-S evidence after larger E stops, re-open continuation via E detector preserving independent accepted A identities. Rebuild accepted ledger from final E plus evidence. Remove invalid S from accepted list.
5. Order_B feedback: keep step1 shared stages, repeat remaining state with legs; optional StopAll reconcile, independent S root restoration, ensure ledger, rediscover legs. Equal semantic leg signature -> return original direction state of pass; repeated non-equal signature -> error; maximum eight passes. No guessed convergence.

## TB-M03 — Requested-range selection and final visibility

Collect range Blue/A by source where reusable; if nonreusable compute full geometry with appropriate flags, S requires A requires Blue regardless of display flags. Full S uses full eligible A and accepted/candidate S. E full state retained. Apply initial A/S display collision rules. Supplement missing independent E donors only for StopAll (do not replace already accepted donor identity). Optional StopAll reconcile; restore independent S roots, ensure audit; rediscover final Order_B and require exact signature equals converged state. Register legs. Capture pre-range accepted references for bridge joins. Apply lifecycle final visibility to full candidates and collect primary groups before range clipping. Clip A/S/E/StopAll by source range inclusive; filter invalid A/S. Mark Blue internal using all behavior reactions then public Blue filter. Internal behavior helper currently copies lists. Prepare OrderAudit with all calculation-accepted A, visible range plus required physical identities, validate physical/cause invariant.

## TB-M04 — Primary, projection and reversal

Primary owner = bearish for both, otherwise requested direction. Only if primary loaded, full E detector exists and explicit lifecycle path: finalize opposite direction, build full primary groups and full audits for both; NativePrimaryOrders callback registers confirmed primary and refreshes its audit. Detect in native primary coordinates, reconcile final labels through visible end, reprepare visible audit preserving previously required identities. Resolve StopAll physical ownership and validate. Serialize legacy and optional additive bridge from SAME selections; append primary arrays if computed. If primary transition index <= visible end, replace direction groups with [independent regimes](15_Trend_Reversal.md), derive activeDirection. Then apply bounded True/False per segment. Final envelope carries versions, enable flags, requested timeframe and actual visible bucket epochs, directions and telemetry. No price rounding; timings rounded to two decimals only. CLI success prints compact JSON/exit0; ordinary exceptions print error JSON/exit1.

## TB-M05 — Dependencies and failure handling

Feedback is the only bounded eight-pass loop here, not a general E/Reaction/primary limit. Geometry and business acceptance remain owner modules. Full stage output maps and partial detector state are mutable; no blanket transaction in batch. Live transport wraps input append transaction, not an empirical equivalence guarantee. Stage callback may fail; no silent catch except explicitly described fallback. See [Live](18_Live_Bridge.md), [Serialization](19_Serialization.md), [RAW](21_RAW_Aggregation_Contract.md) and [T/F](22_True_False_Exact_Contract.md) for exact interface behavior. EngineBundle and MarketContext are frozen slotted reference records, not deep immutable copies. E/lifecycle may be null; primary defaults null. MarketContext defaults index_offset zero and both initial trend flags false. Its candle arrays and delegated indexes remain reference objects. PipelineState and FullDirectionState are mutable slotted reference records. PipelineState retains directional maps, initial geometry and native result references, with primary_result/live_stages default null. FullDirectionState holds authoritative full-range E/S, Blue/A, invalid identity sets, candidates and initial S; construction itself does not deep-copy those fields.

## Detailed orchestration procedures

### TB01 — progress_events_to
Context manager: set context-local progress sink, yield control, restore previous token in finally even on exception. No result payload.

### TB02 — emit_progress
Construct status/label/details event; optional durationMs rounded to two decimals. If sink exists call it; otherwise emit QG_PROGRESS prefix and compact JSON to stderr, flushed. Sink/encoding errors propagate. No market change. Details are merged after status and label, and a supplied non-null duration overwrites durationMs with a two-decimal rounded telemetry value. Exact null selects compact stderr JSON with flush; non-null sink is called directly.

### TB03 — timed
Read performance counter, emit start, invoke work and return its result. Finally accumulate elapsed milliseconds by label in supplied timings and emit completion even on work error. Telemetry only. The start emission is outside the try; on its failure work is not called. Completion telemetry runs in finally after work return or error, with unrounded accumulated duration in the timings map. A failure in finally can supersede the work result or exception.

### TB04 — load_module
Create import specification from name/path; missing spec/loader raises RuntimeError. Create module, register in sys.modules, execute loader, return module. Dynamic external implementation conditional on supplied path. The null-spec test short-circuits before reading the loader. The module is registered under the specification name before execution; execution failure has no local rollback of that registration.

### TB05 — load_engine
Delegate TB04 with fixed reaction_engine module name.

### TB06 — local_datetime
Epoch-keyed cache; miss converts epoch in Asia/Tehran then removes timezone marker, stores and returns naive datetime. A non-null cache hit returns the same stored object. Conversion strips timezone metadata without converting the Tehran wall clock to UTC.

### TB07 — epoch
Datetime-keyed cache; miss attaches Tehran timezone and truncates timestamp with int; stores and returns. Timezone attachment replaces any existing tzinfo rather than converting the input instant; timestamp conversion uses native int truncation toward zero. Zero is a valid cached result.

### TB08 — display_epoch
Datetime directly delegates TB07. Otherwise cache by input string, parse year-month-day hour:minute:second, convert and cache. Parse failures propagate. The datetime branch includes subclasses and bypasses the display cache. The other branch uses its input key as supplied and exact native parse format; no error fallback.

### TB66 — parse_arguments
Require reaction,Blue,A,S engine paths (aliases accepted), data path,timeframe,from/to,direction bullish/bearish/both. E and lifecycle paths optional. Blue/A/S/PLPH flags enabled/disabled default enabled; bridge-output switch; raw-timeframe default1. Require timeframe and raw-timeframe >=1. argparse failures propagate. Return namespace. Analysis timeframe check precedes RAW timeframe check; both are native integers from parser, require >=1. The parser does not independently check from/to ordering or positivity of timestamps. Required paths are Path conversions; E/lifecycle optional; bridge-output store_true; primary and three behavior flags default enabled. Native parser failures propagate.

### TB67 — load_engines
Time and dynamically load configured Reaction,Blue,A,S and optional E paths with expected module names. Lifecycle default pipeline/lifecycle_engine.py always loaded; primary module PL_PH_detector.py loaded if flag enabled (missing attr defaults disabled). Return EngineBundle. Load order Reaction, Blue, A, S, optional E, lifecycle, optional primary. E uses exact non-null path; lifecycle uses truthiness fallback and always loads. Primary flag missing defaults disabled, exact enabled loads pipeline PL_PH_detector without a separate timed wrapper. Configured modules remain conditional dependencies.

### TB71 — create_e_detector
Construct E detector with full market bounds, trend/opposite reactions and resets, S zones, initial audit, blocked First times, exceptions, invalid S identities, Order_B legs, lifecycle.sequence_priority, direct geometry TB72. Only pass live continuation/scope when supplied. Full range is zero through len(candles)−1, even if caller supplies a narrower display range. Opposite direction delegated to chronology; direct geometry closes over supplied detector map. Only non-null continuation adds both live keyword arguments; default E exceptions immutable empty frozenset, blocked/invalid sets nullable.

### TB72 — direct_geometry
Invoke provided live order_geometry callback with direction's detector and requested geometry bounds/gate if present; otherwise call detector.first_order_reaction_after_gate. Provided order_geometry is checked by exact non-null, not truthiness or callable validation. It receives detector selected by requested geometry direction and same gate/bounds; otherwise delegate that detector's native method. Exceptions propagate.

### TB73 — calculate_full_direction_state
Compute full direction state. If no shared stages, timed Blue then A, create full-range S detector with opposite resets and initial Order geometry; run S (live callbacks where provided), retain initial S copy. Else reuse shared Blue/A/S detector and initial S, not the previous E. Snapshot S candidates. Filter S audit by eligible A source; create initial E with feedback scope and detect. Apply lifecycle S eligibility; if size changed identify blocked S source times (set membership or TypeError fallback list); recreate E with valid S and blocked sources and detect. Fresh stages require null shared_stages and assert non-null E engine. Blue/A use live callbacks only with non-null live; initial S constructed full-range, then native detect or live S. Save initial S as a shallow list copy. Reuse shares Blue/A/detector references and original initial_s_zones, but creates fresh current S list from that initial snapshot; candidate list independently copied. Live E/geometry attributes read only when live non-null. Before E, build accepted A source-time set from S detector eligibility and filter its Order audit. Initial E scope is (feedback_index, initial). Lifecycle S reconciliation triggers only on differing lengths, not changed content at equal size. Try set membership for blocked S source times and catch TypeError across that derivation, retrying list membership. Recreate E with valid S and blocked First times in s-reconciliation scope, detect, then assign valid S.
Execute A visibility helpers, then split ALL S-eligible A by dominant S/E stops with original S candidates and no StopAll; callbacks E parent stop and S A-stop from confirmation; collect stage-invalid A. Derive invalid A and S identities and stage-invalid S descendants; remove stage-invalid S from active S. Accepted A excludes invalid; resolve Order context with S audit, previous E blocked times, invalid A, pending S A sources, opposite reactions, A first stop from source, accepted E stops, opposite confirmation, mutable exceptions. Recreate final E using accepted orders, blocked/exceptions/invalid S/legs; detect. The two candidate_a visibility calls are executed but their result is not passed to dominant-stop validation: that call receives a shallow list of ALL S-eligible A, original S candidates, current E and empty StopAll. Its mutable stage-invalid set is an output argument. The parent-stop label is selected by attribute presence; A-stop confirmation directly indexes trend_reactions at int(reaction_number)−1 without a local bounds guard. Invalid A and stage-invalid A are separate identity sets, each projected to source-time membership for descendant S selection from original candidates. Both S identity sets use (source_time,int source_index). At this stage only stage-invalid S is removed from current S; other invalid S is retained until the final filter. Accepted A source times exclude exact invalid identities; pending S A sources use all candidates. resolve_order_context receives a copied blocked-time set and mutable exception output set. Its A-stop callback starts from recorded source time, unlike the earlier dominant-stop confirmation callback. Accepted E stop set uses tuple position 1 only for non-null parent_stop results (one call per E); no local event validation. Final E rebuild uses accepted Orders, blocked Firsts, exact E parent exceptions, all invalid S roots, current B legs and live hooks. Scope is (feedback_index, final); the new detector and its detected list replace previous E references.
Reconcile shared Order stops using accepted initial audit and E ledger; if S rows change, replace candidates by (a source, source) identity, recreate shared-order E and detect once. Filter calculation S candidates by stage-invalid; find consumed S evidence after larger E stop; for each evidence/owner find current E owner by physical source/time; if present build continuation_chain_from_s with independent accepted A identities and replace_with_earlier_continuation. Rebuild accepted E audit with supplemental S evidence. Remove all invalid S from active list. Return FullDirectionState incl full Blue/A, E detector/results, S detector, invalid sets, candidates and initial S. Callback errors propagate; this orchestrates existing engine rules rather than inventing them. Shared Order entries concatenate accepted_orders values before E audit values without a local deduplication. Native list inequality triggers one rebuild; candidate replacement uses exact (a_source_time,source_time) with last map duplicate winning, otherwise original object. Scope is (feedback_index, shared-order). No convergence loop in this block. Consumed-S search excludes stage-invalid candidates only. Independent A Order identities are a frozenset of accepted_orders keys. For each evidence pair, first current E with equal integer source index and exact source time is selected; missing owner skips. Each replacement updates E before next evidence, not a snapshot lookup. After continuation replacement rebuild accepted audit from final E with every consumed S evidence item (preserve order, no dedup here). Then filter active S by all invalid S identities. FullDirectionState retains candidate and initial S lists separately from final S.

### TB74 — calculate_direction_with_order_b_feedback
Start empty B legs/seen signatures/shared stages; at most eight passes. Run TB73 with current legs and pass scope; save initial shared stages. For optional StopAll reconcile lifecycle, else copy E and empty StopAll. Restore independent S roots and ensure accepted audit. Discover accepted reset legs from full reactions/resets, eligible/invalid A, S/E/StopAll, detectors and priority, optional live finder. Compare old/new order_b_leg_identity; equal returns original state of pass (temporary local E list is not assigned to state.e_zones). Repeated new identity raises nonconvergence; otherwise remember and repeat. After eight raise. Start with empty legs and seen set; pass indexes 0–7. shared_stages captures the first returned state only, reused on later iterations; E state recalculated per TB73. Initial empty signature is not inserted into seen here. Optional StopAll uses same enable contract as final visibility; absent flag copies state E and uses empty StopAll. Local E restoration and audit ensure precede reset-leg discovery. Live finders are obtained only if live is non-null, with feedback/pass scope; no local Order selection is reconstructed. Equality of new and old signatures wins before seen membership. Return current pass state, not local restored E list (detector mutations may remain). Repeated changed signature raises before insertion; otherwise remember and replace legs. Exhaustion after eight passes raises, with no partial-success fallback.

### TB75 — prepare_pipeline_state
Requested directions from args; any Blue/A/S enabled requires both reaction directions. Reusable full context iff E exists and S enabled. Initialize state maps. Full: create both geometry UnifiedReactionDetector for full history with matching initial trend flag; batch detect timed or live reactions; derive internal ownership; report if callback. Initial Order geometry closures capture specific opposite direction and delegate live or detector. Calculate both full directions if primary exists else requested; TB74 each, explicit lifecycle path controls StopAll; store all outputs/maps and report. Nonfull: create initial geometry finder for both, detect required directions full independently; internal ownership if behavior enabled else empty identity sets. Return PipelineState with retained optional live stages. Requested both is ordered bullish then bearish; behavior flags independently require both native Reaction directions. Reusable context requires non-null E and enabled S, not an explicit lifecycle flag. All directional state maps start empty. Full reusable branch constructs both full-history detectors regardless of requested output. Directional initial trend flags are gated by matching direction. Null live uses each detector.detect; non-null live uses shared live.reactions. Ownership is live callback or native tuple element 2. Non-null report callback runs after ownership, before subsequent lifecycle work. Geometry closures capture each opposite direction as a default, not the final loop value. They preserve gate index, end and exact event in native call order, independent of public Reaction ownership. Full lifecycle calculation expands to both directions only when primary module exists. For each calculation direction call feedback with explicit lifecycle-path non-null flag (other reusable prerequisites already satisfied). Stage callback is invoked after state return but before publishing all nine directional map entries. Exceptions propagate; no blanket rollback. Nonreusable path still creates both independent A-stop geometry finders, but runs native Reaction only for required directions; it does not use live.reactions here. Ownership calls native behavior views only when any behavior module enabled, otherwise two separate empty sets. Return requested directions, full maps and supplied live reference.

### TB76 — calculate_direction_range_state
Need Blue if Blue/A/S enabled; reuse full Blue clipped by source range or detect from full reactions/chronology; else empty. Need A if A/S enabled; reuse clipped full A or detect from Blue; else empty. If S enabled, full-context uses full candidates/accepted S and eligible A (not clipped); otherwise construct full-range S detector with opposite data and initial geometry, detect and store detector, S candidates accepted and A replaced by eligible. Return range state including full E copy and invalid sets from maps (empty defaults). No final display filtering here. Blue is required by any enabled Blue/A/S flag. Reusable path clips stored lines by inclusive integer source index only; nonreusable path detects with full native result and chronology, no local clip here. Disabled dependency yields empty list. A uses same inclusive source-only clipping for reusable state or full native detection otherwise; S enabled overwrites A with full eligible A. Reusable S lists are retained references; nonreusable creates detector, stores it and aliases accepted S to detected candidates. E is copied; invalid sets retain stored references or fresh defaults.
