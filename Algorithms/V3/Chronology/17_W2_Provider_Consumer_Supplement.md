## Active chronology correction

Previous README summary: | Order A/B | Strictly later exact confirmation; same main First permitted. |

Previous CH23 wording: Order_A post-stop: First >= gate main, confirmation strictly later. Native search uses upper bound of stop on confirmations. Independent geometry may map to canonical identity or number zero; wins only if (First,confirmation) lexicographically earlier.

Current qualification: Stopped-A Order_A selection (SOrderAuditMixin): native confirmation strictly after the A stop and First >= gate main. Independent geometry also requires First >= gate main and initial confirmation strictly after the A stop; a canonical identity remap recomputes confirmation without reapplying that local strict threshold. Independent geometry may map to canonical identity or retain number zero; it wins only if (First,confirmation) is lexicographically earlier.
